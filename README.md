# [Edukio — Site institucional](https://edukio.com)

Site de apresentação do Edukio, com informações sobre o projeto e acesso ao sistema web, ao aplicativo Android e à extensão para Chrome.

## Prévia

[![Prévia do site Edukio](imagens/home_page.png)](https://edukio.com)

## Conteúdo

- Apresentação do Edukio e de seus recursos.
- Links para acessar o sistema web e instalar o aplicativo Android e a extensão para Chrome.
- Equipe, parceiros e contato.
- Páginas de privacidade e termos de responsabilidade.
- Redirecionamento de `/valida` para `https://app.edukio.com/valida`.

## Tecnologias

HTML, CSS/SCSS e JavaScript, com Bootstrap, jQuery e Gulp para preparação dos arquivos e desenvolvimento local.
